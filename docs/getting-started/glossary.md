# Glossary

- `resource`: a self-contained RedM package
- `fxmanifest.lua`: the resource manifest file
- `native`: a game engine function exposed to scripts
- `framework`: an RP layer such as VORP, RSG, or RedEM
- `adapter`: a compatibility layer that hides framework differences
- `dataset`: structured reference data, usually JSON
- `front matter`: YAML metadata at the top of a markdown file
