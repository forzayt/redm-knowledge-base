# Best Practices

- one topic per file
- one dataset per file
- one behavior per example
- short pages with predictable slugs
- repeat the same section order on comparable pages

## For AI indexing

- put the exact topic in the title
- keep the first paragraph direct
- use bullet lists for enumerations
- include source URLs in front matter
- avoid mixing explanation, data, and code templates in one page
