# Overview

This repository is a doc-first RedM knowledge base designed for AI retrieval.

## Core idea

- split knowledge into many focused pages
- keep filenames stable and predictable
- store machine-readable metadata in YAML front matter
- keep structured reference data in JSON

## What this repo should answer

- how to structure RedM resources
- how Lua behaves in RedM scripts
- which framework patterns are available
- which native databases and discovery sources are useful
- how to use the common modding tools

## Recommended reading order

1. `docs/getting-started/resource-structure.md`
2. `docs/getting-started/fxmanifest.md`
3. `docs/lua/reference.md`
4. `docs/frameworks/abstraction.md`
5. `docs/natives/overview.md`
6. `docs/tooling/modding-workflow.md`
