# Blips API

## Common surfaces

- create a blip from coordinates
- create a blip attached to an entity
- create a radius or area blip
- adjust sprite, color, scale, and route state

## Design notes

- keep handle storage centralized
- remove blips on resource stop
- prefer descriptive names for blips shown to players
