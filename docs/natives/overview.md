# Native Overview

This repo should treat native docs as structured reference pages, not one large dump.

## Recommended sources

- alloc8or native DB for database-style lookups
- nativewrappers/rdr3-natives for markdown-native docs
- VORPCORE/RDR3natives for a JSON-native corpus and tooling
- femga/rdr3_discoveries for discoveries and examples

## Documentation strategy

- one native or small related family per page
- keep hash, namespace, parameters, returns, and examples close together
- maintain a dataset for hashes and aliases
