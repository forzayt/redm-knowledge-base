# Lua Reference

Lua 5.4 is the language baseline most RedM script authors should understand.

## What matters most for RedM

- tables and table constructors
- functions and closures
- locals and lexical scope
- metatables and metamethods
- coroutines and yields
- module loading and package behavior
- strings, patterns, and formatting

## Lua 5.4 manual focus

- basic concepts
- control structures
- expressions and precedence
- standard libraries
- the C API, if you are interfacing with native or embedded code

## Programming in Lua focus

- idiomatic functions and closures
- iterators
- modules and packages
- object-style patterns with tables and metatables
- data persistence patterns
