# RSG Setup

## Base requirements

- add the RSG core resource to your server
- ensure the core starts before dependent scripts
- align inventory and SQL resources with the framework you are using

## Notes

- the public sources show `rsg-core` and `rsg-inventory` as important repositories
- use `ns-lib` compatibility notes if you want cross-framework behavior
