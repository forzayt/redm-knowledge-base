# VORP API

## Main surfaces

- `GetCore()` for the core table
- user and character getters and setters
- callback and webhook helpers
- modules for entities, blips, inputs, prompts, points, zones, events, dataview, and streaming

## Useful events

- character selected
- player spawned
- revive, respawn, heal, and level-up events
