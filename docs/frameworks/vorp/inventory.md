# VORP Inventory

VORP exposes inventory APIs for both client and server use.

## Common operations

- fetch inventory items
- fetch a single item record
- fetch server-side item metadata
- check weight or carry capacity
- get user ammo and weapon records

## Notes

- the inventory module is a key part of the VORP API surface
- keep item docs in `datasets/items.json` and reserve this page for behavior and usage
