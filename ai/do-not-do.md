# Do Not Do

- Do not bundle unrelated topics into one markdown file.
- Do not hide source URLs in free-form text only.
- Do not add large code samples unless the page is specifically about that pattern.
- Do not rely on undocumented behavior when a documented API exists.
- Do not assume a single framework if the page is meant to be cross-framework.
