# Contributing

Keep changes optimized for retrieval:

- one topic per file
- short files with narrow scope
- stable names and folder layout
- consistent front matter
- cite source URLs in page metadata

## Editing rules

- prefer Markdown for explanations and examples
- prefer JSON for structured reference data
- prefer Lua for reusable code patterns
- avoid giant catch-all files

## Page checklist

- title present in front matter
- category present in front matter
- tags present in front matter
- sources present in front matter
- page answers one question or one topic

## File naming

- use lowercase names
- use hyphens for multiword files
- use folder names for broad topic groups
- use `index.md` only when a folder needs a landing page
